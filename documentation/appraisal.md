## Review Appraisal Logs

Save an unedited copy of appraisal_delete_log.csv in the reports and logs folder, as evidence of what we reviewed.
During appraisal, we'll be making an edited version of appraisal_delete_log.csv with rows from both logs that are confirmed for appraisal.
The appraisal_check_log.csv is not saved to reports and logs until after review, so we can document our decisions.

The appraisal logs are generated by searching columns we believe have any probability of showing an appraisal category, 
which are topics, file paths, office notes, and fill in text fields (data for mail merge templates).
It results in too many false positives to search all columns, 
due to columns like names and addresses that can match keywords but would never indicate appraisal.

If metadata for an export changes, or we get a metadata file we have not previously received,
it needs to be evaluated for if it could indicate appraisal, and if so added to the df_search() functions.

Appraisal categories: 
* academy applications
* case mail (requests for help with individual situation) 
* job applications to work in the congressional office
* letters of recommendation 
* routine office transactions (flag requests, tours, etc.)

The routine office transactions are based on exact topic matches, so they do not need review. 
The other categories are based on keywords that are not guaranteed to be appraisal and do require review.

### Appraisal delete log

The appraisal delete log is based on more detailed matches and will most likely be appraisal.

Using the appraisal tips and tricks below, 
remove the rows for any that clearly should not be deleted for appraisal.
If it is ambiguous, leave them in the log.

Make a GitHub issue for any common patterns with these false positives that should be skipped when appraising future exports.

### Appraisal check log

The appraisal check log is based on the most generic term(s) we could think of that might indicate appraisal,
to help us find new patterns.
There will likely be a lot of false positives.

Using the appraisal tips and tricks below, identify any rows that should be deleted for appraisal.
If it is ambiguous (e.g., the topic could be an issue or case mail and there are no notes), it should not be deleted.

Copy any rows that should be deleted to the edited version of appraisal_delete_log.csv within AppraisalCopy,
and then delete the review column from appraisal_delete_log.csv.
Move appraisal_check_log.csv with the review column to the reports and log folder once review is complete.

Make a GitHub issue for any common patterns that indicate appraisal that should be part of the delete log when appraising future exports.

### Appraisal tips and tricks

Copy the log from Hub to your local machine for faster response times if the file is large.

Open in Excel to use filters for the review.
If the log is too big to open in Excel, open in a plain text editor.
If there are obvious patterns that do not need to be reviewed, write a script to read the log and make a copy without them.
If not, split into multiple files of acceptable size and review each in Excel.

Add a new column for results.
For appraisal_delete_log.csv, this is a temporary column to keep track of which ones we've decided on.
For appraisal_check_log.csv, this also serves as a permanent record of our decision.

Start by identifying ones without enough information to make a decision.
These have blank or non-descriptive document, notes, and fill-in (if it has that).
If they are in the delete log, delete as appraisal. If they are in the check log, do not delete.

Common indicators for appraisal:
* Privacy form or PARF referenced
* Staffer signature shows them only responsible for casework (part of fill column)
* Notes about your problem/situation or a family members problem/situation
* If the note is that it isn't case or casework, still count as casework since it was sensitive enough to be considered
  
Common indicators for not appraisal:
* Forwarding to another office is not enough, as that could be for more information
* Some label a row "intern" because it was written by the intern, so it isn't enough on its own to be a job application
* Recommendations for public office
* Requests for interviews if it likely to be an interview of the congressperson
* Related to a piece of legislation
* Has pro/con/neutral position

## Run Script in Appraisal Mode

### Script preparation

Prior to running the script, verify:
* The appraisal_delete_log.csv in AppraisalCopy has all rows to be deleted, including from appraisal_check_log.csv and routine office
* Add topics for restriction review to restrictions list in restriction_report() 
* Calculate the number of files in the documents folder, to check the right number of files were deleted

### Script command

`python path/to/script input_directory appraisal`

The input_directory is the path to AppraisalCopy/name_constituent_mail_export

### Script actions and outputs

All outputs are saved in AppraisalCopy. 

* Deletes letters due to appraisal (except for form letters)
* restriction_review.csv (some exports have 1 report per review category)

### Script QC
* Verify the number of files in the documents folder decreases by the expected amount (number of files in the deletion log without a path error)


* Verify the number of files in the deletion log matches the number in appraisal delete log


* Check a few files in the log, both deleted and not found, are not in the export

## Folder Level Review

Review folders with the letters as an additional check for private information missed by the metadata review.
This is done after the script runs in appraisal mode and deletes files based on the metadata,
to avoid any of these files showing up in the script's log as not found.

When checking files, copy a sample and only open the copy, or it risks metadata changing.
Select the sample based on file names and formats, to get at least one of each type.
Look at all files with a name that suggests privacy concerns.

Check the form letter folder for filled in privacy forms, tour lists with social security numbers, and other privacy issues.

Check all other folders except indivletters and objects (too large and rarely organized, so rely on metadata) for folders or subfolders that suggest restrictions.

Even if the folder is named casework, check it. If it is just form letters or other templates, it is ok to keep.
Only delete if it is about an individual's situation.

If you decide to delete, that process is TBD.
Metadata for these files needs to be added to the file_deletion_log.csv, alongside the files deleted by the appraisal mode of the script.
